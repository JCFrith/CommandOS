# Core Philosophy

CommandOS is NOT a dashboard.
It is NOT a CRM.
It is NOT a project management tool.
It is NOT a flight management application.

It is an Executive Operating System.

Every screen must answer one question:

> What requires my attention right now?

Everything else is secondary.

# Development Principles

- Build for a 10+ year lifespan.
- Favor maintainability over cleverness.
- Separate UI, business logic, services, persistence, and AI.
- Never hardcode production data.
- Use services for all external APIs.
- Components must be reusable, typed, documented, accessible, and keyboard navigable.
- Prefer TanStack Query, Zustand, React Hook Form, and Zod.
- Use Tailwind + shadcn/ui.
- Motion should communicate state, not decorate.
- Target Lighthouse 95+.
- WCAG AA accessibility minimum.
- Never expose secrets.
- Test every feature.
- Keep documentation current.
- Use feature branches and meaningful commits.
- Strict TypeScript. No unnecessary `any`.

---

# AI Development Rules

- Extend instead of rewrite.
- Preserve backwards compatibility.
- Ask before major architectural changes.
- Never remove existing functionality without justification.
